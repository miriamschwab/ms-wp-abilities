# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub instead: **Security > Advisories > Report a vulnerability** on
this repository.

Include the plugin version, the ability or file affected, steps to reproduce,
and what an attacker could do with it.

## Supported versions

Fixes land in the latest release only.

## Where to report

| Finding | Where |
|---------|-------|
| An ability, a permission callback, the `rest-write` hard-block list, the audit log, the admin screen | here |
| MCP Adapter: transport, sessions, authentication | [WordPress/mcp-adapter](https://github.com/WordPress/mcp-adapter/security) |
| WordPress core, including the Abilities API | [WordPress HackerOne](https://hackerone.com/wordpress) |
